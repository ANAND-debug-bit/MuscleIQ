<h3>Why I made this website ?</h3>

<hr>

<p>
  I made this website because as a gym freak I ususally need to depend on my gym trainer for each and everything from exercise and food , I got bored of asking again and again and if u ask the web there is a lot of information which is ofc not standardised so i built this site which gives you the right data by selecting any part of muscle from a real human body.
</p>

<h2>Some cool features</h2>

<ul>
<li> Muscle man with both front and backside muscles shown </li> 
  <li> Site is broadly divided into 3 categories to solve the purpose of exercise , food and weight to use for each equipment according to experience lvl</li>
  <li> Super realistic and easy approach to get the desired data for any muscle just by clicking on that muscle directly from the muscle man </li>
  <li> With each exercise it is given the number of sets and the way to do that exercise</li>
  <li> With each food item suggested the serving size is also given </li>
  <li> In weight calculator section with each weight for particular exercise the muscle which is affected and with a note is also there </li>
<li> With end , Disclaimer is also given as muscle strength is subjective to any perosn </li>
